Set up reminders on your phone
  1. Install ntfy (App Store or Google Play).
  2. Tap + → Subscribe to topic, type your exact topic above, server ntfy.sh.
  3. Allow notifications when asked (iPhone: Settings → ntfy → Allow Notifications, Time Sensitive on).
  4. Create a countdown with a reminder. The box sends it within ~30s of the reminder time.

Push alerts

Alerts go to the ntfy app on your iPhone (topic antman-iphone-80f30bef). Send a test to make sure they come through.

How it works

Watchers run on the Linux box. Status refreshes every 45s; this screen refreshes every 30s. All times are Eastern (ET).

Risky Drops only watches and links. It never buys, adds to cart, checks out, or stores payment info. You check out yourself.
